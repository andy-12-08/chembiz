# Preserved evaluation results

This directory retains one current, evidence-bearing result set:

- `2026-09-27-v0.1.1`: all 12 frozen questions run once from a recorded clean source commit, with structured outputs, scores, metadata, report, and limitations.

Earlier development runs and redundant status-response snapshots were removed from the default branch to reduce duplication and make the current evidence easy to review. They remain recoverable from the immutable `v0.1.0` release tag.

The current results are an internal prototype evaluation against a curated draft key. They have not received independent domain-expert validation. See the report and release technical report for complete limitations.
